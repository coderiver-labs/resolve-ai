# Resolve AI

An AI-powered support system that helps users troubleshoot problems, identify issues, and create support tickets with AI assistance.

## Project Status

🚧 **Currently in Development**

Resolve AI is an ongoing project. Features and architecture are being developed incrementally.

## Planned Features

- AI-powered conversational support
- Intelligent issue categorization
- AI-assisted support ticket creation
- Staff assignment and issue tracking
- Ticket status and resolution management

## Tech Stack

- Python
- Django REST Framework
- Ollama / LLM integration *(planned or in progress)*

## Development

This project is actively being developed. Features and documentation may change as development progresses.
